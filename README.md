
# Gap Meter 98 Deluxe

Contador digital de Gaps Federativos baseado nos videos do canal 1155 do ET

## Features Insalubres

- Conta +1 gap
- Conta -1 gap
- Não tem Reset


## Instalação Seca

Instalando no Windows 7

    Baixe o arquivo nos Releases
    Instale
    Conte seu Gap Federais :)
